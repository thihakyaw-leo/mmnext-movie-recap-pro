# MMNext Movie Recap Pro - User Guide\n\n## Quick Start\n1. Launch the app\n2. Import a local video or YouTube URL\n3. Use the workspace in the desired mode\n\n## Modes\n- Common Editing: trim, overlays, ratio/fill\n- Splitter: plan and render parts\n- Narrator: plan, translate, TTS, render\n- Exact Dubbing: edit Burmese text and gender per source row\n\n## Jobs & Recovery\n- Jobs are stored under ~/.mmnext/jobs (configurable via MMNEXT_JOBS_DIR)\n- Completed REAL transcript jobs can be reopened explicitly from Jobs\n\n## Diagnostics\n- Settings -> Diagnostics provides a runtime report\n- Logs can be exported from the bottom log drawer
